# Internal Documentation

This directory contains development and audit documentation that is useful for maintainers but not part of the public-facing documentation.

## Files

- **APPLYING_TO_YOUR_MODEL.md** - Guide for applying the ARC Taxonomy framework to custom models
- **AUDIT_VERIFICATION_REPORT.md** - Detailed verification of technical audit claims (October 2025)
- **CLEANUP_SUMMARY.md** - Summary of repository cleanup actions and their impact

## Purpose

These documents track:
- Development decisions and their rationale
- Audit findings and verification results
- Repository maintenance history
- Internal design discussions

For public-facing documentation, see the main `docs/` directory.
