# Figure Repository

This directory contains all figures generated for the ARC Taxonomy paper and additional analysis visualizations. **Not all figures appear in the final paper** - many are kept for reference, exploratory analysis, and potential future use.

---

## Figures Used in Paper

### Primary Figures (Published)
- **smoking_gun_694f12f3.png** - The compositional gap "smoking gun" (Fig 3 in paper)
  - Shows 99% cell accuracy vs 18% grid accuracy on A2 tasks
  - Generated by: `scripts/generate_smoking_gun_figure.py`
  - Data: `outputs/atomic_lora_training_summary.json`

- **category_distribution.png** - Distribution of 400 re-arc tasks across 9 categories
  - Generated by: `scripts/generate_category_distribution.py` (likely)

- **compositional_gap_sensitivity.png** - Threshold sensitivity analysis
  - Generated by: `scripts/generate_compositional_gap_sensitivity.py`

## Regenerating Figures

Most figures can be regenerated using scripts in `scripts/`:

```bash
# Main paper figures
python scripts/generate_smoking_gun_figure.py
python scripts/generate_compositional_gap_sensitivity.py

# Additional analysis figures
python scripts/generate_arc_agi_2_comparison.py
python scripts/generate_failure_concentration.py
python scripts/generate_s3_performance_profiles.py
```

**Note:** Regeneration requires:
- Completed experiments in `outputs/`
- Taxonomy data in `data/`
- Python packages: `matplotlib`, `seaborn`, `pandas`, `numpy`

---

## Figure Format

- **Format:** PNG (publication quality)
- **Resolution:** 300 DPI minimum (where applicable)
- **Style:** Consistent color scheme and fonts
- **Size:** Optimized for two-column academic papers

## Purpose of This Collection

While not all figures made it into the final paper, they represent:
1. **Exploratory analysis** that informed the paper's direction
2. **Alternative visualizations** considered during writing
3. **Detailed breakdowns** that may be useful for:
   - Supplementary materials
   - Reviewer responses
   - Future publications
   - Presentations

Keeping them in the reproduction package ensures full transparency and provides resources for anyone extending this work.
